# RockBond Background Images

Put page background images in this folder. Files in `public/backgrounds` are served from `/backgrounds/...`.

Expected filenames:

- `explore-map.jpg` - Explore page map hero background.
- `gym-card.jpg` - Explore top rated gym card image.
- `spot-summit-vault.jpg` - The Summit Vault card background.
- `spot-peak-fitness.jpg` - Peak Fitness card background.
- `spot-stone-grove.jpg` - Stone Grove outdoor crag card background.
- `spot-campus-gym.jpg` - Campus Climbing Gym card background.
- `spot-castle-rock.jpg` - Castle Rock outdoor crag card background.
- `event-yoga.jpg` - Explore first event thumbnail.
- `event-social.jpg` - Explore second event thumbnail.
- `progress-quote.jpg` - Climbing Progress quote card mountain image.
- `rank-help-hero.jpg` - Rank Progression Help hero image.
- `friend-route.jpg` - Friend Profile climbing journey route image.
- `chat-route.jpg` - Active Chat route image card.
- `circle-alpine.jpg` - Community Circles featured Alpine Pioneers background.
- `circle-gear.jpg` - Gear Nerds circle thumbnail.
- `circle-indoor.jpg` - Indoor Technicians circle thumbnail.
- `circle-details.jpg` - Circle Details hero image.
- `circle-chat-route.jpg` - Circle Chat route image card.
- `session-location-map.jpg` - Create Session location map image.
- `session-hero.jpg` - Session Details hero image.
- `profile-journey-trad.jpg` - Profile journey traditional climb thumbnail.
- `profile-journey-gym.jpg` - Profile journey gym thumbnail.
- `profile-journey-alpine.jpg` - Profile journey alpine thumbnail.
- `badge-peak-master.jpg` - Badge Details hero and Achievement Wall thumbnail for Peak Master.
- `badge-speed-demon.jpg` - Achievement Wall thumbnail for Speed Demon.
- `badge-first-ascent.jpg` - Achievement Wall thumbnail for First Ascent.
- `badge-night-crawler.jpg` - Achievement Wall thumbnail for Night Crawler.
- `badge-multi-pitch.jpg` - Achievement Wall thumbnail for Multi-Pitch.
- `badge-dyno-master.jpg` - Achievement Wall thumbnail for Dyno Master.
- `badge-crag-legend.jpg` - Achievement Wall thumbnail for Crag Legend.
- `badge-trailblazer.jpg` - Achievement Wall thumbnail for Trailblazer.
- `journey-detail-main.jpg` - Journey Session Detail main climbing image.
- `journey-detail-side.jpg` - Journey Session Detail secondary climbing image.
- `journey-detail-map.jpg` - Journey Session Detail map preview image.

Use `.jpg`, `.png`, or `.webp`; if you change the extension, update `src/index.css` accordingly.
